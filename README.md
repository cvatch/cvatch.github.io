# ∞ GrowTye's Website

Static site (no Jekyll/Node build). Uses the Stylish Portfolio template by Start Bootstrap.

Local dev
- Option A: `python3 -m http.server 8080`
- Option B: `npm i` then `npm start` (random free port), or `npm run start:fixed` (8080)
- Open: `http://localhost:8080/`

Structure
- Home: `/index.html` (shared assets from `/css`, `/js`, `/img`)
- Referrals: `/referrals/` (page-specific `css/` and `img/` to match legacy styling)
- NFT Gallery: `/deepnft/` (page-specific `css/` and `img/` to match legacy styling)

Notes
- Ads and Clippy removed.
- Legacy Jekyll files and Node/Grunt tooling removed.
